# kamyu VPM Listing

A VPM package listing for installing VRChat avatar tools made by kamyu through the VRChat Creator Companion (VCC).

## Reporting issues

Report bugs and request features for any of these packages in this repository's [Issues](https://github.com/kamyu1537/vcc-listing/issues/new/choose). Pick **Bug report** or **Feature request**, then fill in the package name and version.
